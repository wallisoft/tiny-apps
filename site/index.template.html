What is TinyApps?

A little shop of one-job tools from Wallisoft. No bloat, no telemetry, no sign-up — just readable scripts and small installable apps you can open before you run. Installed apps stick around and can be scheduled; one-shot scripts are there when you want them. More land here as they're built; several come from tinkering inside the bigger Visualised family.

Got a tiny tool to add? They live in the open on GitHub — wallisoft/tiny-apps. Each app is one folder (a short app.vml, an icon, and its scripts or release downloads); open a pull request and it joins the shelf. The repo's Submitting an app guide walks you through it.
